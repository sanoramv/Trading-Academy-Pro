# Quiz Template

Use for `weekly_tests/`, `monthly_exams/`, `docs/36_Quizzes/`, and
`docs/37_Assessments/`.

## Header
```
Title:
Covers Lessons: [XX.YY]–[XX.YY]
Total Questions:
Passing Score: 75%
Time Suggested:
```

## Section A — Recall (definitions, facts)
Multiple choice / fill-in-the-blank. Tests whether terminology and mechanics
were retained.

## Section B — Application (scenario-based)
"Given this chart / this balance sheet / this scenario, what would you do and
why?" Tests whether the concept can be applied, not just recited.

## Section C — Judgment (risk/psychology-aware)
Questions that require weighing risk management or psychological discipline,
not just "what pattern is this." Correct answers should never reward
reckless behavior even if it "would have worked" in the example.

## Answer Key
Numbered answers with a one-line rationale each — never just the letter.

## Scoring Guide
| Score | Interpretation |
|---|---|
| 90–100% | Mastery — proceed |
| 75–89% | Passing — proceed, but review flagged weak items |
| 50–74% | Not passing — revise flagged lessons before proceeding |
| <50% | Re-teach — do not proceed, schedule remedial lesson |

## Weak Area Logging
After scoring, log any missed topics into `progress_tracker/` under the
student's weak-areas list so future lessons/quizzes can re-test them.
