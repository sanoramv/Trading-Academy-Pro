# Trading-Academy-Pro

A complete, self-paced, university-level trading and investing curriculum —
built to take someone from **zero market knowledge** to **thinking like a
professional institutional trader**, covering both **Indian (NSE/BSE)** and
**global (US-led)** markets side by side.

> **Educational content only. Not investment advice.** Markets involve risk of
> loss. Nothing in this repository is a recommendation to buy or sell any
> security. See `MASTER_SKILL.md` §6 for full content standards.

---

## What This Is

Trading-Academy-Pro is structured like an open-source software project, not a
single sprawling document. Every concept — from "what is a stock" to
"gamma exposure and dealer positioning" — gets its own carefully written
Markdown lesson, following one consistent, rigorous template (see
`MASTER_SKILL.md` §3). Lessons are:

- **First-principles** — no assumed prior knowledge.
- **Cross-referenced** — every lesson links prerequisites and next steps.
- **Dual-market** — Indian and US examples in the same lesson.
- **Risk-first** — risk management is taught before returns, everywhere.
- **Testable** — every lesson ships with a quiz, answers, and homework.

## How to Use This Repository

1. Start at `LEARNING_PATH.md` — it tells you the order to read things in.
2. Use `CURRICULUM.md` as the full map of everything that exists or is planned.
3. Use **[`INDEX.md`](INDEX.md)** as the complete, linkable table of contents —
   every lesson, quiz, cheat sheet, flashcard deck, case study, worksheet, and
   glossary entry, each with its estimated reading time, difficulty level, and
   prerequisites, so you can jump straight to what you need.
4. Copy `progress_tracker/STUDENT_PROGRESS_TEMPLATE.md` and `market_journal/JOURNAL_TEMPLATE.md`
   for your own copy to track your journey.
5. Work module by module. Do the quiz and homework before moving on.
6. If you're using this with an AI tutor, point it at `MASTER_SKILL.md` first —
   that file defines how it should teach you.
