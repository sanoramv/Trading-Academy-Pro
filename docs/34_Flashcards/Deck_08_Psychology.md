# Flashcard Deck 8 — Trading Psychology

> Covers Module 28 (Trading Psychology). Part of Module 34.

| Front | Back |
|---|---|
| What is the "knowing-doing gap"? | The failure to consistently execute a known, sound rule under real, live trading pressure. `[28.01]` |
| What emotional state tends to peak near market tops? | Euphoria (maximum greed). `[28.02]` |
| What emotional state tends to peak near market bottoms? | Despondency/capitulation (maximum fear). `[28.02]` |
| What does confirmation bias distort? | Information gathering — seeking only evidence that confirms an existing belief/position. `[28.03]` |
| What does recency bias distort? | Pattern recognition — overweighting recent events versus the full journaled sample. `[28.03]` |
| What does loss aversion describe? | Losses being felt more intensely (roughly ~2x) than equivalent gains, per Kahneman & Tversky's Prospect Theory. `[28.03]` |
| What is tilt? | An emotional disruption state, typically triggered by a loss, that impairs decision-making. `[28.04]` |
| What is revenge trading? | An impulsive, often oversized attempt to immediately recover a recent loss. `[28.04]` |
| What is FOMO in trading? | The urge to enter based on fear of missing a move already in progress, not genuine strategy criteria. `[28.05]` |
| What is overtrading? | Excess trade volume diluting a strategy's tested expectancy. `[28.05]` |
| What four sections does a complete trading plan integrate? | Strategy, risk management, position sizing, and psychological circuit breakers. `[28.06]` |
| Why do written rules outperform in-the-moment judgment? | They remove the need for sound judgment under exactly the conditions where it's least reliable. `[28.06]` |
| How does genuine resilience differ from suppression? | Resilience acknowledges the loss constructively; suppression denies it, risking delayed tilt. `[28.07]` |
| What framework helps structure post-loss reflection? | The process-versus-outcome matrix (good/poor process × win/loss outcome). `[28.07]` |
| Do professional traders experience the same psychological patterns as retail traders? | Yes — the difference is structural support and practiced discipline, not immunity. `[28.08]` |
| What does "trading like a professional" realistically mean? | Disciplined self-management of universal human psychology, not achieving a bias-free state. `[28.08]` |
| Is discipline a fixed trait or a trainable skill? | A trainable skill, per professional trading education. `[28.06]` |
| What did Kahneman and Tversky's 1979 paper establish? | Prospect Theory and loss aversion — foundational to behavioral economics. `[28.03]` |
| Who wrote "Trading in the Zone" (2000)? | Mark Douglas. `[28.01]` |
| What is the primary practical countermeasure against tilt? | Pre-committed circuit breakers (mandatory pauses, daily loss limits). `[28.04]` |
