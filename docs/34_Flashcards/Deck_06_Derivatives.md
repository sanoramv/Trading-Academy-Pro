# Flashcard Deck 6 — Derivatives (Futures, Options, Greeks, Volatility)

> Covers Modules 20 (Futures), 21 (Options), 22 (Greeks), 23 (Volatility). Part of Module 34.

| Front | Back |
|---|---|
| What is a futures contract? | A standardized agreement to buy/sell an asset at a set price on a future date. `[20.01]` |
| What is contango vs. backwardation? | Contango: futures price > spot price. Backwardation: futures price < spot price. `[20.05]` |
| What is a call option? | A contract giving the buyer the right, not obligation, to buy at a set strike price. `[21.01]` |
| What is intrinsic value vs. time value? | Intrinsic value is how far ITM an option is; time value is everything else in the premium. `[21.04]` |
| What is the max loss on a long call/put? | The premium paid — fixed and known in advance. `[21.05]` |
| What is the max loss on a naked short call? | Theoretically unlimited. `[21.06]` |
| What is a bull call spread? | Buying a lower-strike call and selling a higher-strike call — defined risk, bullish. `[21.08]` |
| What is an iron condor? | A four-leg, defined-risk options strategy profiting when the underlying stays within a range. `[21.10]` |
| What is the "theta decay trap"? | Being directionally correct but still losing because the move was too slow relative to time value erosion. `[21.12]` |
| What does Delta measure? | Expected premium change per 1-point move in the underlying. `[22.02]` |
| What does Gamma measure? | The rate of change of Delta itself. `[22.03]` |
| What does Theta measure? | Expected daily premium change from time decay alone. `[22.04]` |
| What does Vega measure? | Expected premium change per 1-point change in implied volatility. `[22.05]` |
| What is the difference between historical and implied volatility? | Historical is backward-looking (actual past movement); implied is forward-looking (derived from option prices). `[23.01]` |
| What is India VIX? | NSE's index of expected Nifty volatility over the next 30 days. `[23.02]` |
| What is volatility skew? | The pattern where OTM puts typically carry higher IV than OTM calls for equity indices. `[23.04]` |
| What is "IV crush"? | A sharp drop in implied volatility after an event resolves, reducing premium. `[22.05]`, `[24.10]` |
| What is the volatility risk premium? | The historical tendency for implied volatility to run above subsequently realized volatility. `[23.01]` |
| What is a straddle? | Buying a call and put at the same strike, betting on large movement regardless of direction. `[21.09]` |
| Why is full Kelly rarely used for position sizing in derivatives trading? | Extreme sensitivity to estimation error in win rate/payoff ratio inputs — fractional Kelly is standard practice. `[26.04]` |
