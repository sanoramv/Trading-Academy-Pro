# Flashcard Deck 5 — SMC, ICT & Wyckoff

> Covers Modules 17 (Wyckoff), 18 (Smart Money Concepts), 19 (ICT). Part of Module 34.

| Front | Back |
|---|---|
| What are Wyckoff's Three Laws? | Supply and Demand, Cause and Effect, and Effort vs. Result. `[17.02]` |
| What are the five phases of Wyckoff Accumulation? | Phases A through E, tracing the transition from selling climax to markup. `[17.03]` |
| What is a Wyckoff "Spring"? | A brief false breakdown below support designed to trigger stops before a genuine markup begins. `[17.05]` |
| What is the "Composite Man"? | A mental model treating aggregate large institutional activity as a single, deliberate actor. `[17.06]` |
| What are Smart Money Concepts (SMC)? | A trading framework emphasizing liquidity pools, order blocks, and institutional order flow. `[18.01]` |
| What is a liquidity pool in SMC? | A cluster of resting stop orders above/below a key level that price is drawn toward. `[18.02]` |
| What is an order block? | The last opposing candle before a significant, decisive price move. `[18.03]` |
| What is a Fair Value Gap (FVG)? | A price imbalance left by a rapid move, often revisited later. `[18.04]` |
| What are premium and discount zones? | Price regions above (premium) or below (discount) the midpoint of a defined range, used to time entries. `[18.06]` |
| What does ICT stand for? | Inner Circle Trader — a trading methodology developed by Michael Huddleston. `[19.01]` |
| What is a "Kill Zone" in ICT? | A specific, high-probability time window (e.g., London/New York session opens) for institutional activity. `[19.03]` |
| What is Optimal Trade Entry (OTE) in ICT? | A Fibonacci-based retracement zone (commonly 62-79%) used for entry timing. `[19.04]` |
| What is the "Power of Three"? | An ICT concept describing a session's structure as Accumulation, Manipulation, and Distribution phases. `[19.05]` |
| What is a "Judas Swing"? | A deliberate, misleading initial move designed to trap traders before the genuine directional move. `[19.06]` |
| What is a criticism commonly raised against SMC/ICT? | That some terminology re-labels classical technical analysis concepts without necessarily adding new predictive power. `[18.08]`, `[19.08]` |
| What is Break of Structure (BOS) in an SMC context? | A trend-continuation price break through a prior swing point, [02.05]. |
| What is mitigation, in SMC terms? | Price returning to an order block or FVG to "mitigate" or partially fill the imbalance. `[18.05]` |
| Who is Richard Wyckoff? | An early 20th-century trader whose accumulation/distribution framework remains foundational to institutional price-action analysis. `[17.01]` |
| What distinguishes Wyckoff Distribution from Accumulation? | Distribution marks a topping process before markdown; Accumulation marks a bottoming process before markup. `[17.04]` |
| Does Wyckoff/SMC/ICT analysis eliminate the need for risk management? | No — every framework in this cluster still requires the same position sizing and stop-loss discipline as any other strategy, Module 25/26. |
