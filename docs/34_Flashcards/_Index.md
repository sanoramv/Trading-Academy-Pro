## How to Use This Module
Review one deck per sitting using standard spaced-repetition practice
(e.g., 1 day, 3 days, 1 week, 2 weeks intervals). Each card's back
includes the source lesson ID — if a card doesn't recall easily, revisit
that lesson before moving on.

## Prerequisites for This Module
- The relevant module cluster should already be completed once before
  using its deck for review — these are recall aids, not first-exposure teaching tools.
