> Six capstone projects synthesizing this entire academy into complete,
> deliverable artifacts. Each project brief specifies objectives,
> requirements, deliverable format, and evaluation criteria — the
> student builds the actual deliverable independently.

## How to Use This Module
Complete `[37]`'s Capstone Readiness Exam first. Projects can be
attempted in any order, though Project 1 (trading plan) is recommended
first since Projects 3, 4, and 6 depend on having one in place.

## Prerequisites for This Module
- Capstone Readiness Exam, `[37]`, passed at 75%+.

## What Comes After
Per `LEARNING_PATH.md`, Module 40 (Resources) closes the academy with
curated further-learning material for continuing beyond this curriculum.
