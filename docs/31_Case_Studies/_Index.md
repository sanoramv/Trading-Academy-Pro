# Module 31 — Case Studies

> Every module in this academy has referenced real historical events in
> passing — the 2008 GFC, the March 2020 COVID crash, LTCM's collapse,
> the 1992 Harshad Mehta scam. This module gives ten of the most
> significant events full, dedicated treatment, applying this
> academy's entire framework to real, consequential history.

## Why This Module Exists
Concepts are best cemented by seeing them play out in full, real
context — this module examines ten major market events (five global,
five India-focused) in depth, cross-referencing the specific lessons
throughout Modules 01-30 each event illustrates.
