# Module 26 — Position Sizing

> Module 25 established WHY and roughly HOW MUCH to risk per trade
> (the 1% rule and variants). This module builds the specific
> mathematical methods that turn that principle into an exact number of
> shares, lots, or contracts for any given trade.

## Why This Module Exists
"Risk 1% per trade" still requires a formula to convert into an actual
position size — this module provides several, from the simplest
(fixed fractional) to the more sophisticated (volatility-based, Kelly
Criterion), plus the special considerations options and scaling
introduce.
