# Module 16 — Volume Profile

> Module 15 organized price by time. This module applies the identical
> auction-theory philosophy but organizes price by *volume* instead —
> Volume Profile, the modern, volume-based sibling framework to Market
> Profile, now the more commonly used variant on most retail platforms.

## Why This Module Exists
Volume Profile has become the more widely available, commonly used
variant of profile-based analysis on modern charting platforms,
addressing Market Profile's core limitation (time ≠ participation,
`[14.01]`) by measuring volume directly. This module deliberately
mirrors Module 15's structure so the parallels and differences are clear.
