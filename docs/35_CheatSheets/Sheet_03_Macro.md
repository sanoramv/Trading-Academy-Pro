# CheatSheet 3 — Macro & Global Markets

> Covers Modules 04-06. Part of Module 35.

## Business Cycle Stages (`[05.08]`)
```
EXPANSION -> PEAK -> CONTRACTION (Recession) -> TROUGH -> (repeat)
```

## Sector Rotation Tendencies (`[27.06]`, historical patterns only)
| Cycle Stage | Historically Favored Sectors |
|---|---|
| Early Recovery | Financials, Consumer Discretionary |
| Expansion | Technology, Industrials, Materials |
| Late-Cycle/Peak | Energy, Commodities |
| Recession | Staples, Utilities, Healthcare |

## Monetary vs. Fiscal Policy (`[05.07]`)
```
MONETARY POLICY: Central bank tool — interest rates, money supply (QE/QT)
FISCAL POLICY:    Government tool — spending, taxation
```

## Yield Curve (`[06.07]`)
```
NORMAL curve:    Short-term yields < Long-term yields
INVERTED curve:  Short-term yields > Long-term yields
                 (widely watched recession signal, NOT guaranteed)
```

## Global Market Correlation Cues (`[04.03]`, `[04.06]`)
- GIFT Nifty / SGX Nifty → overnight Nifty open indicator
- US market close → broad Asian/European session sentiment cue
- Correlation tends to RISE toward 1 during genuine risk-off crises (`[25.06]`)

## Key Global Events Referenced (Module 31)
- 2008 GFC: US subprime → global systemic crisis
- 2020 COVID crash: exogenous shock, V-shaped recovery
- 1998 LTCM: Russia default → correlation breakdown
