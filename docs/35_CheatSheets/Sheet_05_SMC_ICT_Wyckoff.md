# CheatSheet 5 — SMC, ICT & Wyckoff

> Covers Modules 17-19. Part of Module 35.

## Wyckoff's Three Laws (`[17.02]`)
```
1. SUPPLY AND DEMAND -- determines price direction
2. CAUSE AND EFFECT -- accumulation/distribution "cause" determines
   the markup/markdown "effect" magnitude
3. EFFORT VS. RESULT -- volume (effort) should confirm price movement
   (result); divergence warns of a potential change
```

## Wyckoff Accumulation Phases (`[17.03]`)
```
Phase A -> B -> C (Spring/Test) -> D -> E (Markup)
```

## SMC Key Terms (`[18.02]`-`[18.06]`)
| Term | Meaning |
|---|---|
| Liquidity Pool | Cluster of resting stops price is drawn toward |
| Order Block | Last opposing candle before a decisive move |
| Fair Value Gap (FVG) | Price imbalance left by a rapid move |
| Mitigation | Price returning to fill/rebalance an FVG or order block |
| Premium/Discount Zone | Above/below the midpoint of a defined range |

## ICT Key Terms (`[19.02]`-`[19.06]`)
| Term | Meaning |
|---|---|
| Kill Zone | High-probability time window (session opens) |
| OTE | Optimal Trade Entry — Fib retracement zone (62-79%) |
| Power of Three | Accumulation → Manipulation → Distribution |
| Judas Swing | Deliberate misleading initial move before the real move |
