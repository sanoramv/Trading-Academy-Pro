## Order Types (`[01.07]`)
| Type | Behavior |
|---|---|
| Market | Executes immediately at best available price |
| Limit | Executes only at specified price or better |
| SL (Stop-Loss) | Triggers a market order once stop price is hit |
| SL-M | Triggers a limit order once stop price is hit |

## Financial Statements Quick Map (`[07.01]`-`[07.04]`)
```
INCOME STATEMENT: Revenue - Expenses = Profit (period)
BALANCE SHEET:     Assets = Liabilities + Equity (point in time)
CASH FLOW STMT:    Operating + Investing + Financing = Net Cash Change
```

## Key Valuation Ratios (`[09.02]`)
- P/E = Price / Earnings per Share
- P/B = Price / Book Value per Share
- EV/EBITDA = Enterprise Value / EBITDA

## DCF Skeleton (`[09.03]`)
```
Intrinsic Value = Sum of [Projected FCF_t / (1+r)^t] + Terminal Value
```

## Market Structure Basics (`[02.02]`-`[02.05]`)
```
UPTREND:   Higher Highs + Higher Lows
DOWNTREND: Lower Highs + Lower Lows
RANGE:     Neither — oscillating between bounds

BOS = trend CONTINUES through a prior swing point
CHOCH = trend potentially REVERSING
```

## Fundamental Analysis Checklist (`[08.10]`)
1. Top-down macro/sector context
2. Financial statement quality (`[07.06]`)
3. Key ratios vs. peers
4. Competitive moat assessment
5. Management/governance quality
