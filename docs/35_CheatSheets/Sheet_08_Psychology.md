## The Knowing-Doing Gap (`[28.01]`)
```
KNOWLEDGE (rules, plans) --[THE GAP: fear/greed/ego]--> ACTUAL EXECUTION
```

## Fear/Greed Cycle Stages (`[28.02]`)
```
Optimism -> Excitement -> Thrill -> EUPHORIA (top, max greed)
  ...decline...
Anxiety -> Denial -> Fear -> Panic -> Capitulation -> DESPONDENCY (bottom, max fear)
```

## Core Cognitive Biases (`[28.03]`)
| Bias | Distorts |
|---|---|
| Confirmation Bias | Information gathering |
| Recency Bias | Pattern recognition |
| Loss Aversion | Risk-taking behavior (losses feel ~2x worse than equivalent gains) |

## Tilt Cascade (`[28.04]`)
```
Normal Loss -> Emotional Response -> Impaired Judgment ->
REVENGE TRADE (oversized, undisciplined) -> LARGER Second Loss
```
**Countermeasure:** pre-committed circuit breaker (mandatory pause / daily loss limit)

## FOMO Check (`[28.05]`)
```
Does THIS opportunity meet my WRITTEN entry criteria?
  NO  -> This is FOMO. Do not enter. A skip is not a loss.
  YES -> Proceed per plan.
```
