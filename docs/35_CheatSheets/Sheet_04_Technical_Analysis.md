# CheatSheet 4 — Technical Analysis

> Covers Modules 10-16. Part of Module 35.

## Moving Averages (`[10.06]`)
```
SMA = simple average, equal weight all periods
EMA = weights RECENT prices more heavily
```

## RSI Quick Reference (`[10.07]`)
```
RSI > 70  ->  commonly read as OVERBOUGHT
RSI < 30  ->  commonly read as OVERSOLD
(context-dependent — strong trends can stay "overbought" for extended periods)
```

## Candlestick Quick Reference (`[11.02]`-`[11.06]`)
| Pattern | Signal |
|---|---|
| Doji | Indecision |
| Hammer | Potential bullish reversal (at support) |
| Shooting Star | Potential bearish reversal (at resistance) |
| Bullish/Bearish Engulfing | Two-candle reversal signal |
| Morning/Evening Star | Three-candle reversal signal |

## Chart Pattern Quick Reference (`[12.01]`-`[12.10]`)
| Pattern | Type |
|---|---|
| Head & Shoulders | Reversal |
| Double Top/Bottom | Reversal |
| Triangles (Asc/Desc/Sym) | Continuation (usually) |
| Flags/Pennants | Continuation |
| Cup and Handle | Bullish continuation |

## Volume Confirmation Rule (`[14.03]`)
```
Breakout + ABOVE-AVERAGE volume -> higher confidence signal
Breakout + LOW volume -> higher false-breakout risk, [13.04]
```

## Market/Volume Profile Quick Reference (`[15.02]`, `[16.02]`)
```
POC (Point of Control) = price level with HIGHEST traded volume
Value Area = price range containing ~70% of session volume
```
