# Module 07 — Financial Statements

> Macroeconomics (Module 06) explained the environment companies operate
> in. This module teaches you to read the companies themselves — the
> three financial statements every fundamental analysis, valuation, and
> investment decision in this academy ultimately rests on.

## Why This Module Exists
A trader who can read macro conditions and chart structure but cannot
read a balance sheet is missing half the picture needed for genuine
investment analysis (as opposed to pure short-term trading). This module
builds that literacy from zero — assuming no accounting background — and
feeds directly into Module 08 (Fundamental Analysis) and Module 09
(Valuation).
