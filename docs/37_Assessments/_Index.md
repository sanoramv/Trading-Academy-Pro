## How to Use This Module
Take these in the order listed, only after completing every module in
an assessment's stated scope and passing the corresponding Module 36
quizzes at 75%+. Per `MASTER_SKILL.md §5`, never advance past an
assessment scoring below the 75% mastery bar without a remedial review.

## Prerequisites for This Module
- All modules within an assessment's stated scope.

## What Comes After
Per `LEARNING_PATH.md`, Module 38 (Practice) provides hands-on drills
to build the applied skill these assessments test for.
