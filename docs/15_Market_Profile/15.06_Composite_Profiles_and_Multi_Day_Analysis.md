## Core Concepts

### Definition
A **composite profile** aggregates TPO data across multiple sessions
(a week, a month, or any chosen period) into a single combined profile,
revealing the **longer-term Value Area, POC, and range** across that
entire period — directly extending this module's single-session
framework (`[15.01]`-`[15.05]`) to longer timeframes, analogous to how
`[02.08]`'s multi-timeframe analysis extends single-timeframe structure
reading to higher-timeframe context.

### Intuition
Just as a single day's POC reveals that day's most "accepted" price, a
month's composite POC reveals the *entire month's* most accepted price —
tracking how this longer-term POC and Value Area **migrate** over
successive periods (weekly composites shifting higher over several
consecutive weeks, for example) reveals genuine, sustained shifts in
longer-term fair value consensus, distinct from any single session's
potentially noisy, less representative individual profile.

### Mental Model
```
COMPOSITE PROFILE CONSTRUCTION:

  Session 1 TPOs  \
  Session 2 TPOs   \
  Session 3 TPOs    +---> COMBINED into ONE composite profile
  Session 4 TPOs   /       spanning the ENTIRE chosen period
  Session 5 TPOs  /        (e.g., one trading week)

  Composite POC = the single MOST-accepted price across
                   the ENTIRE period (not just one session)
  Composite VA  = the price range containing ~70% of ALL
                   TPOs across the ENTIRE period
```

### Visual Explanation
Tracking composite POC/VA migration across successive weekly or monthly
periods reveals whether longer-term "fair value" consensus is
genuinely shifting (an imbalanced, trending market at the higher-
timeframe level) or remaining stable (a balanced, ranging market at the
higher-timeframe level) — directly paralleling `[15.03]`'s single-session
Normal-versus-Trend-Day distinction, now applied at a longer timescale.

### ASCII Diagram
```
   COMPOSITE POC MIGRATION ACROSS SUCCESSIVE WEEKS
   (illustrative -- tracking a genuinely trending
   higher-timeframe market)

   Week 1 Composite POC:  ---- 100
   Week 2 Composite POC:  ------ 102
   Week 3 Composite POC:  -------- 105
   Week 4 Composite POC:  ---------- 108

   READING: Composite POC consistently MIGRATING HIGHER
   across successive weeks -- genuine, sustained shift in

   CONTRAST -- STABLE/BALANCED higher-timeframe market:
   Week 1 Composite POC:  ---- 100
   Week 2 Composite POC:  ---- 101

   Week 4 Composite POC:  ---- 100
   (POC remaining relatively STABLE across weeks --
    balanced, range-bound higher-timeframe market)
```

### Flowchart
```
[Aggregate TPO data across a chosen multi-session period
 (e.g., one trading week) into a composite profile]
        |
        v
[Extract the composite POC, VA, and range for that period]
        |
        v
[Compare this period's composite POC/VA to the PRIOR
 period's composite POC/VA]
        |
        v
[Is the composite POC MIGRATING consistently in one
 direction across successive periods, or remaining
 relatively STABLE?]
        |
   Migrating -> [Higher-timeframe TREND/imbalance --
                 informs [02.08]'s bias for lower-timeframe
                 session-level analysis]
   Stable    -> [Higher-timeframe RANGE/balance]
```

## Real World Analogy
A composite profile is like aggregating an entire month's restaurant
visitor data into one combined view, rather than looking at any single
night's seating pattern in isolation — a single unusual night (a private
event, an unusually quiet Monday) might show a misleading picture, but
the full month's aggregated pattern reveals the restaurant's genuine,
sustained popular seating preferences, and tracking how this monthly
aggregate shifts from month to month reveals genuine changes in
longer-term customer behavior.

## Indian Market Example
Indian institutional Market Profile practitioners specifically build
weekly and monthly composite profiles for Nifty 50 and Bank Nifty,
tracking composite POC migration as a higher-timeframe bias input
directly feeding into `[15.05]`'s daily open-type classification —
a week showing consistent composite POC migration higher provides
additional confidence for favoring bullish Open-Drive/Open-Test-Drive
interpretations on subsequent daily sessions within that week.

## US Market Example
US institutional futures traders build monthly and quarterly composite
profiles for major index futures, using composite Value Area boundaries
as significant longer-term reference levels — a composite VAH or VAL
from a multi-month period often carries meaningfully more structural
significance than any single session's Value Area boundary, given the
much larger aggregated dataset supporting it.

## Historical Example
Composite profile analysis extends directly from Steidlmayer's original
Market Profile framework (`[15.01]`), representing a natural evolution as
electronic charting and computational capability made aggregating and
displaying multiple sessions' combined TPO data increasingly practical —
a capability considerably more accessible to modern traders using
electronic platforms than it would have been during Market Profile's
original 1980s CBOT floor-trading-era development.

## Institutional Perspective
Institutional multi-strategy desks specifically use composite profile
analysis to inform portfolio-level, longer-term positioning decisions
(connecting to Module 27's portfolio management), distinct from the
session-level, shorter-term decisions informed by single-day profiles —
composite analysis serves the "higher timeframe bias" function within
`[02.08]`'s multi-timeframe framework, applied specifically through
Market Profile's vocabulary.

## Retail Perspective
Retail traders who have built comfort with single-session Market
Profile analysis (`[15.01]`-`[15.05]`) should specifically practice
extending that same skill to composite, multi-session analysis — the
underlying logic transfers directly, requiring primarily a shift in
aggregation period rather than an entirely new analytical framework.

## Professional Insights
Professional Market Profile analysts specifically caution that composite
profiles spanning **too long** a period can obscure genuinely meaningful
recent shifts by averaging them together with older, less relevant data
— choosing an appropriate composite period (weekly, monthly, or
quarterly) requires balancing the benefit of a larger, more statistically
robust dataset against the risk of diluting recent, more relevant
information with older, less relevant history.

## Common Mistakes
- Using an inappropriately long composite period that dilutes recent,
  meaningful shifts with older, less relevant data.
- Not tracking composite POC/VA migration across successive periods,
  missing valuable higher-timeframe trend/balance information.
- Treating composite and single-session profiles as providing identical
  information, rather than recognizing their distinct, complementary
  analytical purposes (higher-timeframe bias vs. session-level detail).

## Misconceptions
- **"Composite profiles are just single-session profiles viewed over a
  longer period, with no additional analytical value."** Composite
  profiles specifically reveal longer-term fair value consensus and its
  migration, information not directly visible from any single session's
  profile alone.
- **"There is one universally correct composite period length (weekly,
  monthly, etc.) for all analytical purposes."** Appropriate composite
  period length depends on the specific analytical purpose and the
  trader's own timeframe (per `[10.04]`'s timeframe-matching principle),
  not a single universal standard.
- **"Composite profile analysis is unrelated to Module 02's multi-
  timeframe framework."** It serves precisely the same "higher timeframe
  bias" function `[02.08]` established, expressed through Market
  Profile's specific vocabulary rather than simple candlestick swing
  structure.

## Key Takeaways
- Composite profiles aggregate TPO data across multiple sessions,
  revealing longer-term Value Area, POC, and their migration over time.
- Composite POC migration across successive periods reveals higher-
  timeframe trend (migrating) versus range/balance (stable) states.
- Composite analysis serves the "higher timeframe bias" function within
  `[02.08]`'s multi-timeframe framework, expressed through Market
  Profile's vocabulary.
- Appropriate composite period length should match the specific
  analytical purpose, avoiding both excessive noise (too short) and
  excessive dilution (too long).

## Quiz

   a) A single session's profile only
   b) An aggregation of TPO data across multiple sessions
   c) A type of candlestick pattern
   d) A dividend announcement

2. What does composite POC migration across successive periods reveal?
   a) Nothing significant  b) Higher-timeframe trend vs. range/balance states  c) Only the prior day's close  d) A currency devaluation

3. How does composite profile analysis relate to Module 02's multi-
   timeframe framework?
   a) It's unrelated  b) It serves the identical "higher timeframe bias" function  c) It only applies to single sessions  d) It contradicts Module 02's framework

4. What trade-off exists in choosing a composite period length?
   a) No trade-off exists  b) Too short risks noise; too long risks diluting recent shifts  c) Longer is always better  d) Shorter is always better

5. True or False: Composite profiles provide identical information to a
   single session's profile, with no additional analytical value.
   a) True
   b) False

## Answers

2. **b)** — Composite POC migration reveals higher-timeframe trend vs. range/balance states.
3. **b)** — It serves the identical "higher timeframe bias" function as `[02.08]`'s framework.
4. **b)** — Too short a period risks noise; too long risks diluting recent, meaningful shifts.
5. **b) False** — Composite profiles reveal longer-term information not visible from any single session alone.
