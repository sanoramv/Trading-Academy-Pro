# [15.05] Using Market Profile for Intraday Bias

> Module: Market Profile · Lesson 5 of 6 · Estimated time: 35 minutes

## Learning Objectives
- Synthesize POC, Value Area, Initial Balance, and profile shape into one intraday framework.
- Learn the "open type" classification system for session starts.
- Build a practical, repeatable intraday bias-assessment process.
- Connect this framework directly to `[13.08]`-`[13.09]`'s range/trend approaches.

## Core Concepts

### Definition
This lesson synthesizes this module's prior components into a practical
**intraday bias framework**, centered on **open type classification** —
how today's session opens relative to yesterday's Value Area and range
shapes the entire day's likely character: **Open-Drive** (opens and
moves directly away from yesterday's value with strong, persistent
conviction — strongest trend-day signal), **Open-Test-Drive** (opens,
briefly tests back into yesterday's range, then drives away — a slightly
less immediate but still strong trend signal), **Open-Rejection-Reverse**
(opens outside yesterday's value, is rejected, and reverses back inside —
suggesting the initial move lacked genuine conviction), and
**Open-Auction** (opens within yesterday's Value Area and continues
auctioning/rotating within a similar range — the clearest range-day
signal).

### Intuition
This framework directly operationalizes everything this module has
built — yesterday's POC/VA (`[15.02]`) provides the reference points,
today's Initial Balance (`[15.04]`) provides the earliest read on
today's character, and the open type classification combines both into
an actionable, early-session bias assessment feeding directly into
`[13.08]`'s range-trading or `[13.09]`'s trend-following approach
selection.

### Mental Model
```
FOUR OPEN TYPES (ranked roughly by trend-day likelihood):

1. OPEN-DRIVE: opens AND immediately drives away from
   yesterday's value with strong, persistent conviction --
   STRONGEST trend-day signal, favor [13.09]'s approach
   immediately

2. OPEN-TEST-DRIVE: opens, briefly tests back toward
   yesterday's range, THEN drives away -- still a strong
   trend signal, slightly less immediate

3. OPEN-REJECTION-REVERSE: opens OUTSIDE yesterday's value,
   gets REJECTED, reverses back INSIDE -- initial move
   lacked conviction, consider [13.08]'s range approach

4. OPEN-AUCTION: opens WITHIN yesterday's Value Area,
   continues rotating within a similar range -- CLEAREST
   range-day signal, favor [13.08]'s approach
```

### Visual Explanation
Each open type is identifiable within the session's earliest minutes,
providing genuinely actionable early guidance rather than requiring the
full session to complete before an approach can be selected.

## Real World Analogy
Open type classification is like assessing a negotiation's early tone
within its first few minutes — a negotiator who opens with an
aggressive, immediately-firm new position and doesn't waver (Open-Drive)
signals a very different likely negotiation trajectory than one who
opens firmly but is quickly talked back toward the previous day's agreed
terms (Open-Rejection-Reverse), or one who opens by simply continuing the
previous day's already-familiar discussion points (Open-Auction) — each
early signal meaningfully shapes expectations for how the rest of the
exchange will likely unfold.

## Indian Market Example
Indian Bank Nifty traders specifically classify each session's open type
within the first 15-30 minutes, using yesterday's Value Area (`[15.02]`)
as the reference — an Open-Drive above yesterday's VAH, confirmed by a
narrow, persistently-extending Initial Balance (`[15.04]`), prompts an
immediate shift to trend-following approaches (`[13.09]`) for that
session, while an Open-Auction within yesterday's VA prompts range-
trading approaches (`[13.08]`) instead.

## US Market Example
US futures traders analyzing S&P 500 E-mini sessions apply the identical
open-type classification framework each morning, using it as one of
their earliest, most actionable intraday bias inputs — professional
Market Profile education specifically teaches this four-type
classification as a core, foundational skill for intraday futures
trading.

## Historical Example
Open type classification, like this module's other components, traces
directly to Steidlmayer's original CBOT Market Profile framework
(`[15.01]`) — representing the practical, actionable synthesis
Steidlmayer specifically developed for traders needing to make real-time
decisions within a session's earliest minutes, rather than only being
able to analyze market character retrospectively after a session's full
completion.

## Institutional Perspective
Institutional Market Profile-based trading desks specifically build
open-type classification directly into their earliest-session decision
protocols — often with formal, written rules for how position sizing and
strategy selection should shift based on the identified open type,
directly mirroring this lesson's flowchart at an institutional scale.

## Retail Perspective
Retail traders applying this framework should specifically practice
open-type classification on historical sessions before real-time
application — since correctly distinguishing Open-Drive from Open-Test-
Drive, or recognizing an Open-Rejection-Reverse in progress, requires
pattern recognition built through deliberate practice, consistent with
this academy's repeated emphasis on practice-based fluency development.

## Professional Insights
Professional Market Profile analysts emphasize that open-type
classification, while providing valuable early guidance, should still be
combined with the broader confluence principles from `[10.11]` —
particularly checking whether the open type aligns with or contradicts
the higher-timeframe structural bias (`[02.08]`), since a strong Open-
Drive against a well-established higher-timeframe trend carries different
risk implications than one aligned with it.

## Common Mistakes
- Committing fully to an approach based on the very first few minutes of
  price action, before the open type is genuinely confirmed.
- Not calibrating open type classification against yesterday's specific
  Value Area, using an arbitrary reference point instead.
- Ignoring higher-timeframe context (`[02.08]`) when interpreting a given
  session's open type.

## Misconceptions
- **"Open type is fully determined within the very first minute of
  trading."** Genuine classification typically requires observing at
  least the first 15-30 minutes, and ideally confirmation from the
  developing Initial Balance (`[15.04]`), not just the literal opening
  tick.
- **"All four open types are equally common."** Open-Auction and Open-
  Rejection-Reverse are generally more common in typical, balanced market
  conditions, while genuine Open-Drive days are comparatively rarer,
  reserved for sessions with unusually strong, immediate conviction.
- **"This framework replaces the need for higher-timeframe context."**
  Professional practice explicitly combines open-type classification with
  higher-timeframe structural bias (`[02.08]`), not as a standalone,
  sufficient signal.

## Key Takeaways
- Open type classification (Open-Drive, Open-Test-Drive, Open-Rejection-
  Reverse, Open-Auction) synthesizes yesterday's Value Area, today's
  Initial Balance, and early profile shape into an actionable intraday
  bias framework.
- Open-Drive and Open-Test-Drive favor trend-following approaches
  (`[13.09]`); Open-Auction and Open-Rejection-Reverse favor range-
  trading approaches (`[13.08]`).
- Genuine classification requires observing at least the session's first
  15-30 minutes, not just the literal opening tick.
- This framework should be combined with higher-timeframe structural
  context (`[02.08]`), not used as a standalone signal.
