# Module 15 — Market Profile

> Modules 10-14 taught classical technical analysis and volume. This
> module introduces Market Profile — a framework organizing price by
> *time spent* at each level rather than sequential candles, developed
> at the Chicago Board of Trade and built on Auction Market Theory.

## Why This Module Exists
Market Profile represents a genuinely different way of visualizing the
same underlying auction this academy has studied since Module 02 —
organizing price data by time-at-level rather than time-sequence. It's
the direct conceptual bridge into Module 16 (Volume Profile) and Module
17 (Wyckoff), both of which assume this module's vocabulary.
