# Module 19 — ICT

> Module 18 gave you Smart Money Concepts' price-structure vocabulary.
> This module adds ICT (Inner Circle Trader) methodology's distinctive
> contribution: explicit time-based and session-based frameworks for
> when institutional activity is statistically more likely to occur.

## Why This Module Exists
ICT methodology, developed and popularized by trader Michael J. Huddleston
("The Inner Circle Trader"), extends SMC's price-structure concepts
(Module 18) with a systematic emphasis on trading session timing —
building directly on Wyckoff's Composite Man framework (`[17.06]`) and
SMC's liquidity/order-block vocabulary (Module 18), while adding time-of-
day and week-based structure largely absent from those earlier
frameworks.
