# Module 08 — Fundamental Analysis

> Module 07 taught you to read a company's financial statements. This
> module teaches you to actually analyze them — turning raw numbers into
> a genuine assessment of a company's quality, using ratios, qualitative
> judgment, and industry context.

## Why This Module Exists
Reading a financial statement and analyzing a business are different
skills. This module bridges that gap, building the ratio toolkit and
qualitative framework that turns Module 07's literacy into genuine
investment judgment, feeding directly into Module 09 (Valuation).
