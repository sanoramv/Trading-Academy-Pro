## How to Use This Module
Take a cluster's quiz only after completing every lesson in its
covered modules. Score using the `templates/QUIZ_TEMPLATE.md` scoring
guide (75%+ to proceed) and log any missed topics into
`progress_tracker/` per `MASTER_SKILL.md §5`.

## Prerequisites for This Module
- The relevant module cluster must be completed first.
