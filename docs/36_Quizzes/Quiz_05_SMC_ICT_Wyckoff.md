2. A brief false breakdown below support designed to trigger stops before a genuine markup begins. `[17.05]`
3. A cluster of resting stop orders above/below a key level that price is drawn toward. `[18.02]`
4. The last opposing candle before a significant, decisive price move. `[18.03]`
5. A specific, high-probability time window (session opens) for institutional activity. `[19.03]`
6-12.
