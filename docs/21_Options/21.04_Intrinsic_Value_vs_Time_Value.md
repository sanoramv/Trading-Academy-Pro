# [21.04] Intrinsic Value vs Time Value

> Module: Options · Lesson 4 of 12 · Estimated time: 30 minutes

## Core Concepts

### Definition
An option's total **premium** decomposes into exactly two components:
**Intrinsic value** — the amount by which an option is currently ITM
(`[21.03]`); for a call, intrinsic value = max(0, underlying price −
strike price); for a put, intrinsic value = max(0, strike price −
underlying price). Intrinsic value can never be negative — an OTM or
ATM option always has zero intrinsic value. **Time value** (also called
extrinsic value) is everything else: Premium − Intrinsic Value = Time
Value. Time value represents the market's assessment of the probability
and potential magnitude of the option becoming more profitable before
expiry, reflecting time remaining and expected volatility.

### Intuition
Intrinsic value answers "what would this option be worth if exercised
right now?" while time value answers "what additional value does the
possibility of favorable movement before expiry add?" — an OTM option
has zero intrinsic value (exercising now would be unprofitable) but can
still command meaningful premium entirely from time value, since there's
still a chance it becomes profitable before expiry.

### Mental Model
```
PREMIUM = INTRINSIC VALUE + TIME VALUE

CALL intrinsic value = max(0, Underlying Price - Strike)
PUT intrinsic value  = max(0, Strike - Underlying Price)

Example (illustrative, call option):
  Underlying = 24,200
  Strike = 24,000
  Premium = 250

  Intrinsic value = max(0, 24,200 - 24,000) = 200
  Time value = Premium - Intrinsic value = 250 - 200 = 50

For an OTM option (Underlying = 23,800, Strike = 24,000):
  Intrinsic value = max(0, 23,800 - 24,000) = 0
  Time value = Premium - 0 = ENTIRE premium is time value
```

### Visual Explanation
As expiry approaches, time value systematically erodes toward zero — an
option's premium at expiry consists ENTIRELY of intrinsic value (zero
time value remaining), since there's no time left for further favorable
movement; this erosion process, called **theta decay**, generally
accelerates as expiry nears, a critical dynamic developed fully in
Module 22's Greeks and `[21.12]`'s theta decay trap discussion.

## Real World Analogy
Intrinsic value and time value are like the components of a lottery
ticket's resale price near a drawing versus far before it — a ticket's
"intrinsic value" would be zero before any numbers are drawn (there's no
guaranteed win yet), but the ticket still commands a price reflecting the
*possibility* of winning (analogous to time value); as the drawing
approaches with no favorable outcome yet confirmed, that "possibility"
premium shrinks, much like an option's time value erodes as expiry
nears without the underlying moving favorably.

## Indian Market Example
Indian Nifty options traders specifically distinguish intrinsic from
time value when evaluating whether an option's current premium seems
reasonable — a deep ITM option trading at a premium barely above its
intrinsic value suggests the market assigns little additional probability
to further favorable movement, useful context before deciding whether to
buy or sell.

## US Market Example
US options traders similarly decompose premium into these two
components routinely, particularly when comparing options across
different expiry dates on the same underlying and strike — options with
more time remaining until expiry command higher time value, all else
equal, since there's more opportunity for favorable movement.

## Historical Example
The formal intrinsic value/time value decomposition became mathematically
rigorous with the development of the Black-Scholes option pricing model
in 1973 (`[21.01]`, `[22.01]` previewed) — providing the theoretical
framework explaining precisely how time value should behave as a
function of time remaining, volatility, and other factors.

## Institutional Perspective
Institutional options market makers price time value using sophisticated
models incorporating implied volatility (Module 23, previewed) — while
retail traders can approximate time value through the simple subtraction
this lesson describes, professional pricing involves considerably more
sophisticated volatility-based modeling.

## Retail Perspective
Retail traders should specifically calculate the intrinsic/time value
split before buying any option, recognizing that paying a large time
value premium for a deep OTM option requires a correspondingly large,
favorable move just to reach breakeven — a discipline directly connecting
to `[21.12]`'s common option buyer mistakes discussion.

## Professional Insights
Professional traders emphasize that time value is not simply a linear
function of time remaining — it typically decays non-linearly,
accelerating meaningfully in the final weeks before expiry, a nuance
Module 22's theta Greek will quantify precisely.

## Common Mistakes
- Assuming a high option premium always reflects high intrinsic value,
  without checking how much is actually time value.
- Not recognizing that OTM options can still have meaningful premium
  entirely from time value.
- Ignoring the accelerating nature of time value decay as expiry
  approaches.

## Misconceptions
- **"An option's premium is entirely determined by intrinsic value."**
  Time value is often a substantial, sometimes majority, component of
  premium, particularly for ATM and OTM options.
- **"OTM options have zero value since they have zero intrinsic
  value."** They retain time value until expiry and can become
  profitable if the underlying moves favorably.
- **"Time value decays at a constant, linear rate."** Decay is generally
  non-linear, typically accelerating as expiry approaches — a nuance
  developed fully in Module 22.

## Key Takeaways
- Premium = Intrinsic Value + Time Value.
- Intrinsic value: max(0, underlying − strike) for calls; max(0, strike
  − underlying) for puts — never negative.
- Time value: everything beyond intrinsic value, reflecting the
  probability and potential magnitude of favorable movement before
  expiry.
- Time value erodes toward zero as expiry approaches, generally
  accelerating (theta decay, covered fully in Module 22 and `[21.12]`).

## Summary
Intrinsic value and time value — together comprising an option's total
premium — decompose an option's price into "what it's currently worth if
exercised" versus "what additional value the possibility of favorable
future movement adds," with time value systematically eroding toward
zero as expiry approaches. This sets up the next lesson's treatment of
long call and long put payoff diagrams, visualizing exactly how these
value components translate into profit and loss across the underlying's
possible price range.
