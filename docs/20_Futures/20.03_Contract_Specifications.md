## Core Concepts

### Definition
Every futures contract has exchange-defined, standardized
specifications: **Lot size** (also called contract size or multiplier)
is the fixed quantity of the underlying asset (or, for index futures,
the fixed multiplier applied to the index value) that one contract
represents — traders cannot buy or sell fractional lots. **Expiry date**
is the specific, predetermined date the contract settles — Indian
equity/index futures historically expired on the last Thursday of each
month, but NSE shifted the F&O expiry day to Tuesday effective September
2025 (monthly contracts now expire on the last Tuesday); always verify the
current expiry day directly from the exchange, since this convention has
changed before and can change again (`[20.06]`, previewed). **Tick size** is the minimum permitted
price increment the contract can move — a contract's price can only
change in multiples of this tick size, not in arbitrary decimal amounts.

### Intuition
These three specifications together determine exactly how much capital
a position requires, how precisely its price can move, and when it must
be closed or rolled over — understanding them is not optional background
detail but essential, practical knowledge required before placing any
real futures trade, since misunderstanding lot size in particular can
lead to dramatically miscalculated position sizing.

### Mental Model
```

NOTIONAL VALUE = Lot Size x Current Price

  Example (illustrative, not current real specs):
  Nifty futures lot size = 25
  Nifty at 24,000
  Notional value = 25 x 24,000 = Rs 6,00,000 per lot

MINIMUM PRICE MOVEMENT = 1 Tick x Lot Size

  Example: Tick size = 0.05 points
  Minimum P&L change per lot = 0.05 x 25 = Rs 1.25 per tick

EXPIRY: last Tuesday of the contract month as of Sept 2025
        (previously last Thursday -- verify current convention
        on the exchange; standard Indian F&O convention, [20.06])
```

### Visual Explanation
Because lot sizes are fixed by the exchange (not chosen by individual
traders) and periodically revised based on the underlying's price level,
traders must always check the *current* lot size before sizing a
position — a lot size used in an older reference source may no longer
be accurate, since exchanges periodically adjust lot sizes as underlying
prices change substantially over time.

## Real World Analogy
Contract specifications are like the standardized packaging sizes at a
wholesale supplier — you can't order "half a box" of a product; you
must order in the supplier's fixed unit sizes, and understanding exactly
how much product (and therefore how much total cost) each standard unit
represents is essential before placing any order, exactly as
understanding a futures lot size is essential before placing any trade.

## Indian Market Example
Indian traders must specifically check the NSE website for current lot
sizes before trading Nifty 50 or Bank Nifty futures — these lot sizes
have been revised by the exchange at various points as index price
levels have changed substantially, meaning a lot size a trader
remembers from an earlier period may no longer be accurate at the time
they actually place a trade.

## US Market Example
US traders using CME's E-mini S&P 500 futures (ES) work with a
well-known, long-standing multiplier (historically $50 per index point)
— illustrating how, unlike some Indian contracts that have seen periodic
lot-size revisions, certain established US contracts have maintained
stable specifications for extended periods, though verifying current
specs remains good practice regardless of market.

## Historical Example
Standardized contract specifications represent one of futures markets'
core historical innovations over informal forward-contract trading
(`[20.02]`) — the Chicago Board of Trade's 19th-century standardization
of grain contract sizes and quality grades was specifically what enabled
the liquid, exchange-traded futures market to develop in the first
place.

## Institutional Perspective
Institutional traders managing large multi-contract positions build
systematic checks into their execution systems specifically to verify
current contract specifications before order placement, recognizing that
manual errors in lot-size assumptions can produce dramatically
mis-sized real-money exposure at institutional scale.

## Retail Perspective
Retail traders should specifically build the habit of checking current
contract specifications directly from the exchange website immediately
before placing any futures trade, rather than relying on memory or
potentially outdated educational material (including this lesson's
illustrative example figures, which are not live, current data).

## Professional Insights
Professional traders emphasize that tick size, while seemingly a minor
technical detail, has genuine practical importance for very short-term,
high-frequency strategies — understanding the exact minimum price
increment affects precise stop-loss and target placement calculations,
particularly for scalping-style approaches.

## Common Mistakes
- Using outdated lot-size figures from memory or older educational
  material rather than checking current, live exchange specifications.
- Miscalculating total notional value or position risk due to lot-size
  errors.
- Not accounting for expiry timing when planning trade duration,
  leading to unplanned rollover situations (`[20.06]`).

## Misconceptions
- **"Lot sizes never change over time."** Exchanges periodically revise
  lot sizes, particularly as underlying index/stock price levels change
  substantially — always verify current specifications.
- **"Tick size is an unimportant technical detail."** It has genuine
  practical importance for precise position sizing and short-term
  strategy calculations.
- **"All futures contracts expire on the same schedule."** Indian
  equity/index F&O follows a monthly expiry convention (last Tuesday as
  of September 2025, previously last Thursday), but this can vary by
  instrument and exchange, and the specific day itself has changed
  before — always verify the specific contract's current expiry.

## Key Takeaways
- Lot size determines the fixed quantity/multiplier per contract —
  notional value = lot size × current price.
- Tick size determines the minimum permitted price movement.
- Indian equity/index futures historically expired on the last Thursday
  of each month, but NSE shifted the F&O expiry day to Tuesday in
  September 2025 (monthly contracts now expire on the last Tuesday) —
  always verify the current expiry day directly from the exchange, since
  this convention has changed before and can change again.
- Always verify current, live contract specifications directly from the
  exchange before trading — these figures can change over time.

## Summary
Contract specifications — lot size, expiry date, and tick size —

minimum price movement, and position duration. This sets up the next

## Quiz
1. What is a futures contract's lot size?
   a) A random number  b) The fixed quantity/multiplier the contract represents  c) The margin required  d) The tick size

2. How do you calculate a futures position's notional value?
   a) Lot size ÷ price  b) Lot size × current price  c) Only the margin amount  d) Price alone

3. What is tick size?
   a) The expiry date  b) The minimum permitted price increment  c) The lot size  d) The margin percentage

4. As of September 2025, when do Indian equity/index futures expire?
   a) The first Monday of the month  b) The last Tuesday of the month  c) Randomly  d) Never

5. True or False: Lot sizes never change over time and can always be relied upon from memory.
   a) True
   b) False

## Answers
1. **b)** — The fixed quantity/multiplier the contract represents.
2. **b)** — Lot size × current price.
3. **b)** — The minimum permitted price increment.
4. **b)** — The last Tuesday of the month, since NSE's September 2025 change (previously the last Thursday — always verify the current convention).
5. **b) False** — Lot sizes are periodically revised; always verify current specifications.
