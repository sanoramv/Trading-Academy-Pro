# Module 20 — Futures

> Modules 01-19 built your foundation in market structure, analysis, and
> "smart money" frameworks — all primarily applied to spot/cash equity
> markets. This module transitions into derivatives, beginning with
> futures contracts: standardized agreements that let traders speculate
> and hedge using leverage.

## Why This Module Exists
Futures are the foundational derivative instrument underlying much of
professional trading, hedging, and the index futures (Nifty/Bank Nifty)
that many of this academy's prior lessons (Modules 03, 17-19) have
already referenced in passing. This module builds a rigorous, complete
understanding of futures contracts before Module 21 introduces options.
