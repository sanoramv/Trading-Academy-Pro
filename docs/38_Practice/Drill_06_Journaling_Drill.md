# Drill 6 — Journaling Drill

> Builds `[24.12]`'s journaling discipline through hands-on practice.

## Instructions
1. Using `[24.12]`'s required fields (date/instrument/strategy, entry/
   exit/size, planned stop/target, result, rule adherence, post-trade
   note), build a journal template in a spreadsheet.
2. Log five hypothetical or real trades using the template — for each,
   explicitly note whether the trade followed your plan exactly (rule
   adherence: yes/no).
3. Classify each of the five trades using `[28.07]`'s process-vs-outcome
   matrix (good/poor process × win/loss).
4. Calculate a rough expectancy from your five trades (acknowledging
   this sample is far too small for statistical validity per `[24.01]`
   — the point is practicing the calculation, not drawing conclusions).

## Worked Example (Hypothetical, 5 trades)
```
Trade 1: +2R, rule adherence YES -> Good Process / Win
Trade 2: -1R, rule adherence YES -> Good Process / Loss (normal variance)
Trade 3: +1.5R, rule adherence NO (moved stop) -> Poor Process / Win (lucky)
Trade 4: -1R, rule adherence YES -> Good Process / Loss (normal variance)
Trade 5: -2.5R, rule adherence NO (oversized after Trade 4's loss,
         a revenge-trading pattern, [28.04]) -> Poor Process / Loss

ROUGH EXPECTANCY (illustrative, N=5, TOO SMALL for real conclusions):
  Win Rate = 2/5 = 40%. Avg Win = (2+1.5)/2 = 1.75R. Avg Loss = (1+1+2.5)/3 = 1.5R
  Expectancy ~= (0.4 x 1.75) - (0.6 x 1.5) = 0.70 - 0.90 = -0.20 (NEGATIVE
  in this small sample)

  KEY OBSERVATION: Trades 3 and 5 (rule violations) are DISTORTING this
  result -- Trade 3's "lucky win" and Trade 5's revenge-driven oversized
  loss are PROCESS failures, not evidence about the underlying
  STRATEGY's genuine expectancy, per [24.12]'s process-vs-strategy distinction.
```

## Self-Check Questions
- Did you honestly log the rule-adherence field, even for trades that "worked out" despite deviation?
- What would your expectancy look like if you excluded the two rule-violation trades? Calculate it.
- Does this drill change how you'd interpret a real, larger sample's expectancy calculation?
