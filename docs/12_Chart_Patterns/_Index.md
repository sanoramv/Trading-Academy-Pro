# Module 12 — Chart Patterns

> Module 11 taught single- and multi-candle patterns spanning a few
> periods. This module scales up to larger, multi-week/multi-month
> formations — Head and Shoulders, Double Tops, Triangles, and more —
> read using the exact same structure-and-context discipline built since
> Module 02.

## Why This Module Exists
Chart patterns are the most visually recognizable technical tool in
popular trading culture — and among the most misapplied, when treated as
shapes to pattern-match rather than as visible summaries of the same
buyer/seller structural battle covered throughout Module 02 and Module
11. This module teaches them as an extension of that structural
literacy, not a new, disconnected topic.
