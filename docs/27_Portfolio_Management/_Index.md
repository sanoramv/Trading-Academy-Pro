# Module 27 — Portfolio Management

> Modules 24-26 built strategy, risk, and sizing discipline at the
> individual-trade level. This module extends that discipline to the
> full portfolio: how multiple positions and asset classes combine,
> diversify, rebalance, and get measured together over time.

## Why This Module Exists
A trader who manages every individual position well can still build an
accidentally undiversified, poorly-constructed overall portfolio — this
module covers asset allocation, Modern Portfolio Theory, correlation in
practice (extending `[25.06]`), rebalancing, sector rotation, the
core-satellite structure, and the standard performance metrics
(Sharpe, Sortino, Alpha, Beta) used to evaluate it all.
