# Module 29 — Algorithmic Trading

> Module 28 closed with systematic, rules-based execution as a partial
> response to psychological challenges. This module explores that
> response in full: what algorithmic trading actually is, how to
> backtest and avoid overfitting, execution algorithms, a simple bot's
> architecture, Indian regulation, and how HFT really works.

## Why This Module Exists
Automating a strategy's execution — removing the in-the-moment
discretion Module 28 identified as psychology's primary attack surface
— is a natural, structural extension of this academy's risk and
discipline themes, and a major, growing part of both Indian and global
markets that any serious trader should understand even if they never build a bot.
