# Module 23 — Volatility

> Module 22 introduced Vega — sensitivity to implied volatility — as one
> of five Greeks. This module makes implied volatility itself the
> primary subject: what it is, how it's measured (India VIX, US VIX),
> how it varies by strike (skew/smile), and how it behaves over time.

## Why This Module Exists
Nearly every strategy in Module 21 and every Greek in Module 22
referenced volatility indirectly — this module gives it full,
dedicated treatment, since accurately reading the current volatility
regime is often what separates a well-timed options strategy from a
poorly-timed one.
