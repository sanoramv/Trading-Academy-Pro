# Module 18 — Smart Money Concepts

> Module 17 gave you Wyckoff's original, foundational theory of
> institutional accumulation and distribution. This module translates
> that theory into the modern vocabulary popularized by contemporary
> "Smart Money Concepts" (SMC) traders — order blocks, fair value gaps,
> liquidity pools, and premium/discount zones.

## Why This Module Exists
Smart Money Concepts represent a modern, price-action-focused
reformulation of Wyckoff's core insight (`[17.06]`'s Composite Man) —
that large, informed operators leave detectable footprints. This module
translates Wyckoff's century-old vocabulary into today's widely-used SMC
terminology, while maintaining the same critical, evidence-based
perspective this academy has applied throughout Module 17.
