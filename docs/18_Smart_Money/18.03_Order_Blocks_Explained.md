## Core Concepts

### Definition
An **order block** in SMC terminology is the last opposite-direction
candle immediately preceding a strong, decisive price move — a **bullish
order block** is the last down-close candle before a strong upward move,
and a **bearish order block** is the last up-close candle before a
strong downward move. SMC theory holds that this candle's price range
represents the specific zone where large operators placed a substantial
concentration of orders, making it likely to act as support (for bullish
order blocks) or resistance (for bearish order blocks) if price returns
to retest that zone later.

### Intuition
Order blocks are SMC's specific, candle-level operationalization of
`[13.03]`'s more general supply/demand zone concept — rather than
identifying a broader zone through visual inspection of a consolidation
area, order block identification provides a more precise, rule-based
method: locate the *specific candle* immediately preceding the strong
move, and treat its range as the actionable zone.

### Visual Explanation
SMC traders typically mark the identified order-block candle's full
high-to-low range as the actionable zone, watching for price to return
to this specific zone later — a retest that holds (price reacts from
within the zone without fully invalidating it) is treated as confirming
the order block's continued validity, closely paralleling `[13.03]`'s
zone-retest logic.

## Real World Analogy
An order block is like identifying the exact final moment a large
institutional buyer placed their last remaining purchase orders before a
product's price began rising sharply — that specific price level becomes
memorable and psychologically significant, since it represents the last
point where that buyer was still willing to acquire at the lower price,
making it a reasonable level to expect renewed buying interest if the
price returns there later.

## Indian Market Example
Indian SMC-influenced traders analyzing Nifty 50 intraday charts
specifically mark the last down-close candle before a strong rally as a
bullish order block, then watch for price to retest that specific
candle's range later in the session — treating a successful bounce from
within that zone as a higher-confidence long entry opportunity than a
generic support level identified through simple visual inspection alone.

## US Market Example
US SMC traders analyzing forex pairs frequently combine order block
identification with the liquidity pool concept from `[18.02]` — looking
specifically for order blocks that formed immediately after a liquidity
sweep, reasoning that this combination represents a particularly
high-confidence zone where large operators both absorbed available
liquidity and established meaningful positioning.

## Historical Example
The specific "order block" terminology and precise candle-level
identification methodology emerged within SMC's 2010s-2020s
popularization (`[18.01]`), representing a more precisely rule-based
refinement of the broader supply/demand zone concept (`[13.03]`) that
has circulated in price action trading literature for considerably
longer.

## Institutional Perspective
Institutional traders do not typically use the specific term "order
block" internally, but the underlying logic — that a price zone
immediately preceding a strong, large-volume move likely reflects
meaningful institutional order concentration — has genuine plausibility
grounded in how large orders are typically built and executed, lending
some legitimate support to the concept's core premise.

## Retail Perspective
Retail traders should specifically practice order block identification
using this lesson's precise, rule-based criteria (last opposite-direction
candle before a strong move) rather than the somewhat looser, more
subjective supply/demand zone identification from `[13.03]` — while
recognizing both approaches describe fundamentally related underlying
market structure.

## Professional Insights
Professional analysts caution that order block identification, despite
its seemingly precise, rule-based definition, still requires meaningful
subjective judgment regarding what constitutes a sufficiently "strong,
decisive" move to qualify — different practitioners applying the same
nominal definition can identify somewhat different order blocks on
identical charts, an important limitation to recognize.

## Common Mistakes
- Treating order block identification as fully objective and precise,
  when meaningful subjective judgment (what counts as a "strong" move)
  remains involved.
- Trading an order block retest without additional confirmation (volume,
  structural context), directly repeating errors this academy has warned
  against since `[13.03]`.
- Not distinguishing a genuine order block retest (reaction from within
  the zone) from a full invalidation (price closing decisively through
  the zone).

## Misconceptions
- **"Order block identification is fully objective, with no subjectivity
  involved."** Meaningful subjective judgment about what constitutes a
  "strong" move remains part of the identification process.
- **"Order blocks are a completely different concept from `[13.03]`'s
  supply/demand zones."** Order blocks provide a more precise, candle-
  level operationalization of the same underlying supply/demand zone
  concept.
- **"Every order block retest results in a strong reaction."** Some
  order blocks fail and are fully invalidated by continued price
  movement through the zone — confirmation remains essential.

## Key Takeaways
- A bullish order block is the last down-close candle before a strong
  upward move; a bearish order block is the last up-close candle before
  a strong downward move.
- Order blocks provide a precise, candle-level operationalization of
  `[13.03]`'s broader supply/demand zone concept.
- Order block identification still requires meaningful subjective
  judgment about what constitutes a sufficiently strong move.
- Confirmation (volume, structural context) remains essential before
  trading an order block retest.

## Summary
Order blocks — the last opposite-direction candle preceding a strong,
decisive price move — provide SMC's precise, candle-level method for
identifying zones where large operators likely established meaningful
positioning, directly extending `[13.03]`'s broader supply/demand zone
framework with more specific identification criteria. This sets up the

   a) The last up-close candle before a decline  b) The last down-close candle before a strong upward move  c) Any random candle  d) A type of moving average

2. What is a bearish order block?
   a) The last down-close candle before a rally  b) The last up-close candle before a strong downward move  c) A dividend policy  d) A bond yield

3. What broader concept does the order block operationalize?
   a) The EMH  b) `[13.03]`'s supply/demand zone framework  c) Dow Theory alone  d) DCF valuation

4. Is order block identification fully objective?
   a) Yes, completely  b) No, subjective judgment about "strong" moves remains involved  c) It requires no judgment at all  d) Only algorithms can identify them

5. True or False: Every order block retest results in a strong price reaction.
   a) True
   b) False

## Answers
1. **b)** — The last down-close candle before a strong upward move.
2. **b)** — The last up-close candle before a strong downward move.
3. **b)** — `[13.03]`'s supply/demand zone framework.
4. **b)** — No, subjective judgment about "strong" moves remains involved.
5. **b) False** — Some order blocks fail and are fully invalidated by continued price movement.
