## How to Use This Module
Each entry gives a one-to-two sentence definition and the lesson ID
`[XX.YY]` where the term is taught in full. This glossary is a lookup
reference, not a substitute for the actual lesson — always follow the
cross-reference for complete context, examples, and nuance.

## Prerequisites for This Module
- None — this module is a reference, usable at any point in the curriculum.
