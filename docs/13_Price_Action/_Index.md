# Module 13 — Price Action

> Modules 11-12 taught named, catalogued patterns. This module teaches
> pure price action — reading raw candle-by-candle and swing-by-swing
> behavior without relying on named patterns at all, the discretionary
> skill underlying everything taught so far.

## Why This Module Exists
Named patterns (Modules 11-12) are useful vocabulary, but skilled
discretionary traders read price more fluidly than any fixed catalogue
of shapes can capture. This module teaches that underlying skill
directly — supply/demand zones, breakout/fakeout reading, pullback
classification — building a discretionary playbook that doesn't depend
on any single named pattern appearing.
