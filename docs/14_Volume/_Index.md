# Module 14 — Volume

> Volume has been referenced constantly since `[10.08]` as a confirming
> tool. This short, focused module gives it the dedicated, deeper
> treatment it deserves before the academy moves into the advanced,
> volume-centric frameworks of Market Profile, Volume Profile, and
> Wyckoff.

## Why This Module Exists
Volume is simultaneously the most under-studied and most repeatedly
referenced tool in this academy so far. This module closes that gap
directly, before Modules 15-17 build entire analytical frameworks
(Market Profile, Volume Profile, Wyckoff) on top of volume literacy this
module establishes.
