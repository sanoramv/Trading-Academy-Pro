# Module 10 — Technical Analysis

> Modules 05-09 taught you to value a business from its fundamentals. This
> module teaches the other major lens professional traders use: reading
> price action itself. It builds directly on Module 02's market structure
> foundation, adding the classical technical analysis toolkit — trendlines,
> moving averages, oscillators, and a disciplined analytical checklist.

## Why This Module Exists
Fundamental analysis (Modules 07-09) tells you what to buy; technical
analysis increasingly informs when. This module gives classical technical
analysis the same first-principles treatment as every other topic in this
academy — assuming Module 02's structure literacy, but assuming nothing
about indicators, chart types, or the historical Dow Theory foundation
this entire discipline rests on.
