# Module 28 — Trading Psychology

> Modules 24-27 built strategy, risk, sizing, and portfolio discipline.
> This module addresses the behavioral layer beneath all of it: why
> traders with sound frameworks still deviate from them, and how to
> build the psychological resilience to actually follow through.

## Why This Module Exists
Nearly every module in this academy has referenced psychology in
passing — `[24.12]`'s discipline-vs-strategy-failure distinction,
`[25.08]`'s written-rulebook rationale, `[26.01]`'s conviction-sizing
warning. This module gives psychology its own full, dedicated treatment,
covering the fear/greed cycle, specific cognitive biases, revenge
trading, FOMO, discipline-building, and resilience after losses.
