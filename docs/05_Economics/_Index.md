# Module 05 — Economics

> Markets are downstream of the real economy. This module builds the
> economic first principles — demand/supply, inflation, interest rates,
> GDP, employment, fiscal/monetary policy, business cycles — that every
> later macro, fundamental analysis, and valuation lesson will assume you
> already understand.

## Why This Module Exists
Traders who skip economics tend to treat markets as a self-contained
game of chart patterns and indicators, disconnected from the real forces
(inflation, interest rates, growth, employment) that actually drive
longer-term price behavior. This module gives those real forces the same
first-principles treatment the rest of this academy gives chart reading,
so Modules 06 (Macroeconomics) and 08–09 (Fundamental Analysis/Valuation)
have solid ground to build on.
