# Module 09 — Valuation

> Module 08 taught you to assess business quality. This module teaches you
> to translate that assessment into an actual number — an estimate of what
> a business is genuinely worth, and how to compare that estimate to the
> current market price.

## Why This Module Exists
"This is a great company" and "this is a great investment at this price"
are different statements — this module closes that gap, building the
relative and intrinsic valuation toolkit that completes the fundamental
analysis arc begun in Modules 07-08, before the academy shifts to
technical analysis in Module 10.
