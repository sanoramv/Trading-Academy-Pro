# LEARNING_PATH.md — Recommended Student Sequencing

`CURRICULUM.md` is the syllabus map (what exists). This file is the *order* a
student should actually walk through it in. Some modules are learned linearly;
others (Psychology, Risk Management) run in parallel with everything else from
day one because they are habits, not one-time topics.

Track legend:
- **Core Path** — every student walks this, in order.
- **Parallel Track** — start alongside Core Path Stage 2 and continue throughout.
- **Elective / Specialization Track** — chosen after Stage 6 based on the
  student's goal (discretionary trader, options trader, quant/algo trader).

---

## Stage 0 — Orientation
- Read `README.md`, `MASTER_SKILL.md` (student-facing summary), `ROADMAP.md`.
- Set up `progress_tracker/` copy and `market_journal/` copy.

## Stage 1 — Foundation (Weeks 1–2)
- Module 01 — Foundation (all lessons, in order)
- Module 02 — Market Structure (lessons 1–4 only; revisit 5–8 in Stage 3)
- Module 03 — Indian Market (lessons 1–6)
- Checkpoint: `weekly_tests/week_01_foundation.md` (generated after Module 01
  is complete), `weekly_tests/week_02_market_structure_indian.md`

## Stage 2 — Economics & the Macro Lens (Weeks 3–4)
- Module 05 — Economics (all)
- Module 06 — Macroeconomics (all)
- Module 04 — Global Market (all)
- Module 03 — Indian Market (lessons 7–10)
- **Begin Parallel Track: Module 28 — Trading Psychology (lessons 1–3)**
- **Begin Parallel Track: Module 25 — Risk Management (lessons 1–2)**

## Stage 3 — Company Analysis (Weeks 5–6)
- Module 07 — Financial Statements (all)
- Module 08 — Fundamental Analysis (all)
- Module 09 — Valuation (all)
- Parallel Track continues: Psychology (4–5), Risk Management (3–4)

## Stage 4 — Technical Analysis Core (Weeks 7–9)
- Module 02 — Market Structure (lessons 5–8, revisited with full context)
- Module 10 — Technical Analysis (all)
- Module 11 — Candlesticks (all)
- Module 12 — Chart Patterns (all)
- Module 13 — Price Action (all)
- Module 14 — Volume (all)
- Parallel Track continues: Psychology (6), Risk Management (5–6)
- Checkpoint: `monthly_exams/month_02_technical_analysis.md`

## Stage 5 — Advanced Market Reading (Weeks 10–12)
- Module 15 — Market Profile (all)
- Module 16 — Volume Profile (all)
- Module 17 — Wyckoff (all)
- Module 18 — Smart Money Concepts (all)
- Module 19 — ICT (all)
- Parallel Track continues: Psychology (7–8), Risk Management (7–8)

## Stage 6 — Derivatives Core (Weeks 13–16)
- Module 20 — Futures (all)
- Module 21 — Options (all)
- Module 22 — Greeks (all)
- Module 23 — Volatility (all)
- Module 26 — Position Sizing (all)
- Module 27 — Portfolio Management (all)
- Checkpoint: `monthly_exams/month_04_derivatives.md`

## Stage 7 — Strategy Synthesis (Weeks 17–18)
- Module 24 — Trading Strategies (all)
- Module 31 — Case Studies (all, if not already read incrementally)
- Full trading plan project from `docs/39_Projects/`

---

## Stage 8 — Specialization Tracks (choose one or more)

### Track A — Discretionary / Price Action Trader
- Deep re-read: Modules 12, 13, 17, 18, 19
- `docs/38_Practice/` chart-marking drills
- `docs/39_Projects/` — build and paper-trade a discretionary playbook

### Track B — Options & Derivatives Trader
- Deep re-read: Modules 20, 21, 22, 23
- `docs/38_Practice/` options payoff worksheets
- `docs/39_Projects/` — build and paper-trade a theta-selling income system

### Track C — Quant / Algorithmic Trader
- Module 29 — Algorithmic Trading (all)
- Module 30 — Quantitative Trading (all)
- `docs/39_Projects/` — build and backtest a simple rule-based system

## Ongoing Throughout (all stages)
- `docs/32_Daily_Market_Analysis/` — apply concepts to real, current sessions
  as they are learned (retrospective analysis of already-closed sessions only).
- `market_journal/` — log every paper trade or live trade with reasoning.
- `docs/33_Glossary/`, `docs/34_Flashcards/`, `docs/35_CheatSheets/` — used as
  reference, not sequential reading.

## Certification Gate
A student is considered "Trading-Academy-Pro certified" only after passing:
1. `docs/37_Assessments/Beginner_Certification.md`
2. `docs/37_Assessments/Intermediate_Certification.md`
3. `docs/37_Assessments/Full_Academy_Final_Exam.md`
4. Completion of at least one project from `docs/39_Projects/`

See `docs/37_Assessments/` (generated later in the build sequence) for exact
passing criteria.
